Selected Endpoint: allSets
This endpoint allows for users to get all the names and ids for the sets currently in the database.

You would want to do an API call like this: https://www.optcgapi.com/api/allSets/

Here is what the return data will look like:
                
                    [
                        {
                            "set_name": "Romance Dawn",
                            "set_id": "OP-01"
                        },
                        {
                            "set_name": "Paramount War",
                            "set_id": "OP-02"
                        }
                    ]

card_name
color
set_id
set_name
rarity
card_type
card_cost
card_power
attribute
